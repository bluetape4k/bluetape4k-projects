# Catalog Ref 2026-05-25-01

## 배경

공유 `bluetape4k-dependencies` catalog에 ASM, AWS Kotlin SDK, Apache Fory
의존성 업데이트가 반영됐다.

## 결정

기본 `bluetape4kDependenciesCatalogRef`를 `develop`에 떠 있게 두지 않고
`catalog/2026-05-25-01`로 고정한다.

## 결과

Gradle settings는 기본적으로 release train catalog를 가져오며,
`bluetape4kDependenciesCatalogRef` 또는 `BLUETAPE4K_DEPENDENCIES_CATALOG_REF`
override는 계속 허용한다.

catalog 업데이트는 `bluetape4k-hibernate-reactive`에서 Hibernate 7.3.4 test
KAPT 비호환성을 드러냈다. Hibernate processor는 생성된 ANTLR 4.13 parser로
test `@NamedQuery` 선언을 검증하지만, KAPT worker가 더 오래된 ANTLR runtime을
먼저 로드했다. test code에는 static JPA metamodel만 필요하므로 `kaptTest`는
이제 Hibernate processor를 제외하고, `Author`와 `Book`에 대해 checked-in test
metamodel class를 유지한다.

전체 Nightly storage-cache job은 Apache Fory가 1.0.0으로 이동한 뒤 Redisson
test utility ABI 문제도 노출했다. `redisson:4.4.0`은 여전히 자체
`org.redisson.codec.ForyCodec`을 로드하고, map serialization 중 제거된 Fory
memory helper를 호출한다. Testcontainers storage test의 목적은 Redisson의 Fory
통합이 아니라 Redis container wiring 검증이므로, 공유 Redisson test codec은
이제 `LZ4Codec(Kryo5Codec())`를 사용한다.

## 검증

- Settings file이 `catalog/2026-05-25-01`로 업데이트됐다.
- `./gradlew compileTestKotlin --refresh-dependencies --console=plain -PsnapshotVersion=-SNAPSHOT`
- `./gradlew :bluetape4k-testcontainers:dependencyInsight --configuration testRuntimeClasspath --dependency org.apache.fory --console=plain -PsnapshotVersion=-SNAPSHOT`
- `./gradlew :bluetape4k-testcontainers:dependencyInsight --configuration testRuntimeClasspath --dependency redisson --console=plain -PsnapshotVersion=-SNAPSHOT`
- `./gradlew :bluetape4k-testcontainers:test --tests "io.bluetape4k.testcontainers.storage.RedisClusterServerTest" --console=plain -PsnapshotVersion=-SNAPSHOT`
- `./gradlew :bluetape4k-redisson:test --console=plain -PsnapshotVersion=-SNAPSHOT`

## 향후 가드

조율된 dependency train 업데이트에는 날짜가 있는 catalog tag를 사용한다.
Hibernate processor upgrade가 ANTLR runtime drift로 test KAPT를 깨면, 안정적인
test metamodel symbol만 필요한 module에서는 test processor 실행 제거를 우선한다.
Redisson/Fory ABI가 test 목적에 명시적으로 포함되지 않는 한, 일반적인
Testcontainers smoke test에서 Redisson built-in Fory codec을 사용하지 않는다.
