# 이슈 607/608 1.9.1 Release Prep

## 배경

Milestone 1.9.1에는 `truncateUtf8(maxBytes)` release inclusion issue와 Fory 0.17.0 runtime
compatibility issue가 있었다. Source change는 이미 `develop`에 있었지만 release metadata는 여전히
1.9.0을 가리켰다.

## 결정

`baseVersion`을 올리고, 전용 1.9.1 changelog section을 추가하며, milestone issue를 닫기 전에 current
Fory 0.17.0 API shape을 확인해 1.9.1을 준비한다.

## 결과

`bluetape4k-core`는 `io.bluetape4k.support.truncateUtf8(maxBytes)`를 expose한다.
`ForyBinarySerializer`는 Fory 0.17-compatible `buildThreadSafeForyPool(int)` builder method를 사용한다.

## 검증

- `fory-core-0.17.0.jar`에 대한 `javap`로 `buildThreadSafeForyPool(int)`만 available함을 확인.
- `:bluetape4k-core:test`, `:bluetape4k-io:test`, `:bluetape4k-redisson:test` target test XML aggregate:
  2812 tests, failure 0, error 0.

## 향후 agent 가이드

Patch release 전에는 source readiness와 release metadata를 모두 확인한다: `gradle.properties`,
`CHANGELOG.md`, README version example, generated artifact/BOM evidence.
