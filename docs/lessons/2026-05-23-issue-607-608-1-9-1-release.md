# Issue 607/608 1.9.1 Release Prep

## Context

Milestone 1.9.1 contains a release inclusion issue for `truncateUtf8(maxBytes)`
and a Fory 0.17.0 runtime compatibility issue. The source changes were already
present on `develop`, but the release metadata still pointed at 1.9.0.

## Decision

Prepare 1.9.1 by bumping `baseVersion`, adding a dedicated 1.9.1 changelog
section, and verifying the current Fory 0.17.0 API shape before closing the
milestone issues.

## Outcome

`bluetape4k-core` exposes `io.bluetape4k.support.truncateUtf8(maxBytes)`.
`ForyBinarySerializer` uses the Fory 0.17-compatible
`buildThreadSafeForyPool(int)` builder method.

## Verification

- `javap` on `fory-core-0.17.0.jar` confirmed only
  `buildThreadSafeForyPool(int)` is available.
- Target test XML aggregate for `:bluetape4k-core:test`, `:bluetape4k-io:test`,
  and `:bluetape4k-redisson:test`: 2812 tests, 0 failures, 0 errors.

## Future Agents

Before a patch release, check both source readiness and release metadata:
`gradle.properties`, `CHANGELOG.md`, README version examples, and generated
artifact/BOM evidence.
